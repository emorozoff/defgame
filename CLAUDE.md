# DefGame — заметки для Claude

## Версионирование (ОБЯЗАТЕЛЬНО)

При **любом** изменении кода (даже самом мелком) обнови:

1. Константу `VERSION` в `game.js` (около строки 2)
2. Query-параметр `?v=...` у `<script src="game.js?v=...">` в `index.html`

Оба значения должны совпадать. Это нужно чтобы:
- Игрок видит версию в правом верхнем углу и понимает, что обновление подтянулось
- Браузер сбрасывает кеш и тянет свежий `game.js`

Схема (semver-ish):
- **PATCH** (`0.3.1`) — баланс, фиксы, мелочи
- **MINOR** (`0.4.0`) — новые механики, юниты, враги, сцены
- **MAJOR** (`1.0.0`) — крупные редизайны

Бампай всегда хотя бы PATCH. Никогда не оставляй версию неизменной после правки кода.

## Стек

- Phaser 3 через CDN, без сборки и без npm
- Все ассеты — генерация через `Graphics.generateTexture()` в `BootScene.preload()`
- Деплой: GitHub Pages через `.github/workflows/deploy.yml` на push в `main` и в текущую dev-ветку
- Live: `https://emorozoff.github.io/defgame/`
